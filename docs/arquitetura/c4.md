# Diagramas C4

## Nível 1 — Contexto

```mermaid
flowchart LR
    cliente["Cliente<br/>[Pessoa]<br/>Dono do veículo"]
    funcionario["Funcionários<br/>[Pessoa]<br/>Administrador, Atendente, Mecânico"]
    sistema["Sistema Integrado de Atendimento<br/>e Execução de Serviços<br/>[Sistema]"]

    cliente -- "Consulta o andamento e aprova/recusa<br/>o orçamento (HTTPS/JSON + JWT)" --> sistema
    funcionario -- "Cadastra, abre e conduz as OS,<br/>controla estoque (HTTPS/JSON + JWT)" --> sistema
```

Não há sistemas externos no MVP: o "envio" do orçamento é a disponibilização na API do cliente.

## Nível 2 — Contêineres

```mermaid
flowchart LR
    cliente["Cliente"]
    funcionario["Funcionários"]

    subgraph sistema["Sistema da Oficina (docker compose)"]
        api["API REST<br/>[Contêiner: .NET 10 / ASP.NET Core]<br/>Monólito em camadas, Swagger em /swagger"]
        db[("Banco de dados<br/>[Contêiner: PostgreSQL 17]<br/>Clientes, veículos, OS, estoque")]
    end

    cliente -- "HTTPS/JSON<br/>JWT papel Cliente" --> api
    funcionario -- "HTTPS/JSON<br/>JWT papel de funcionário" --> api
    api -- "EF Core / Npgsql<br/>TCP 5432" --> db
```

## Nível 3 — Componentes da API

```mermaid
flowchart TB
    subgraph api["Oficina.Api"]
        endpoints["Endpoints (Minimal APIs)<br/>Auth, Clientes, Veículos, Serviços, Peças,<br/>Ordens de serviço, Área do cliente, Relatórios"]
        seguranca["Segurança<br/>JWT Bearer, políticas por papel, rate limit"]
        erros["TratamentoDeErros<br/>exceções → ProblemDetails"]
    end

    subgraph app["Oficina.Application"]
        servicos["Serviços de caso de uso<br/>OrdemDeServicoService, PecaService,<br/>ClienteService, VeiculoService, ServicoService,<br/>AuthService, RelatorioService"]
        portas["Portas<br/>IUnitOfWork, ITokenService, ISenhaHasher"]
    end

    subgraph dom["Oficina.Domain"]
        agregados["Agregados<br/>OrdemDeServico, Peca, Cliente,<br/>Veiculo, Servico, Usuario"]
        vos["Objetos de valor<br/>Documento, Placa, Dinheiro"]
        repos["Interfaces de repositório"]
    end

    subgraph infra["Oficina.Infrastructure"]
        dbcontext["OficinaDbContext<br/>Unit of Work + log de eventos de domínio"]
        repositorios["Repositórios EF Core"]
        jwt["JwtTokenService / SenhaHasher"]
    end

    db[("PostgreSQL")]

    endpoints --> servicos
    seguranca --> endpoints
    servicos --> agregados
    servicos --> repos
    servicos --> portas
    agregados --> vos
    repositorios -. implementa .-> repos
    dbcontext -. implementa .-> portas
    jwt -. implementa .-> portas
    repositorios --> dbcontext
    dbcontext --> db
```

As setas contínuas apontam para dentro (Api → Application → Domain). A Infrastructure implementa as interfaces definidas nas camadas internas.
